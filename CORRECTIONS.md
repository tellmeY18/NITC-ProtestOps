# Corrections

Public log of corrections to claims made in posters and decks produced with this toolkit. Posters themselves are local-only and are not stored in this repository; the claims behind them are in `analysis/`.

## Format

```
## YYYY-MM-DD — poster / panel — short title

- **Old claim:** …
- **New claim:** …
- **Why:** …
- **Source:** …
- **Action:** correction panel / story / caption edit
```
